# ارفع تقرير المخزون هنا

ارفع ملف الإكسيل في الفولدر ده (Add file → Upload files → Commit changes)
والموقع بيتحدث لوحده في خلال دقيقتين، والملف بيتشال بعد ما يتقرا.

الملف لازم يكون فيه عمود **كود الصنف**، ومعاه يا عمود **المستودعات الرئيسية**
يا أعمدة المخازن التلاتة: **الانتاج التام(الرياض** و **م جدة الرئيسى** و **مستودع مكة المكرمة**.

⚠️ الريبو عام: الملف بيفضل في تاريخ الريبو حتى بعد ما يتشال، فالأفضل الملف مايبقاش فيه أعمدة أسعار.
