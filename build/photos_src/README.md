# ارفع صور الأصناف هنا

1. سمّي كل صورة **بالكود 14 رقم**، مثلًا `10420111054416.jpg`.
   لو للكود أكتر من صورة (مجموعة لونية تانية): `10420111054416 (2).jpg`.
2. من صفحة الفولدر ده: **Add file ← Upload files**، اسحب الصور، وبعدين **Commit changes**.
3. في خلال دقيقتين الموقع بيتحدث لوحده:
   - الصنف اللي كان "جاري التصوير" بياخد صورته.
   - الصورة المتكررة أو اللي بنفس المجموعة اللونية بتتجاهل.
   - الكود اللي رصيده أقل من 20 مش هيظهر دلوقتي، وهيظهر لوحده لما رصيده يوصل 20.
